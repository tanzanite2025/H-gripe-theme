# 冷灰明亮浮起模式色板

## 定位

本文件是项目明色模式的唯一全局配色规范，适用于 storefront、Admin 和其他使用
`premium-card` 视觉语言的新 UI。它定义颜色、表面层级、操作层级和状态表达；
具体组件仍应遵循各自的布局、交互和无障碍约束。

本规范对应“经典明亮浮起”方案：页面底座使用 Slate-100，卡片使用纯白，
输入和嵌套区域使用 Slate-50，主操作使用 Slate-900，翡翠绿只承担视觉和
状态强调，不作为后台动态配置的默认值。

配色参考图外层的黑色只是文档展示背景，不属于应用主题，也不代表暗色模式。
本文件不覆盖以下内容：

- 图片、视频或素材内部已经存在的文字颜色；
- 第三方支付官方 SVG 的固有颜色；
- `docs/archive/` 或 `nuxt-i18n/docs/archive/` 中仅用于历史记录的旧设计说明；
- 暗色模式的独立主题令牌。

## 核心令牌

### 表面层级

颜色从页面底部到组件顶部逐级变亮。卡片的主要层次来自表面差异，不依赖过重阴影。

| 层级 | 用途 | 色值 | Tailwind 对应 | 说明 |
| --- | --- | --- | --- | --- |
| 页面底色 | `<body>` 全局背景 | `#f1f5f9` | `bg-slate-100` | 比卡片沉一档，形成稳定浮起感 |
| 卡片表面 | `.premium-card`、主要面板 | `#ffffff` | `bg-white` | 实体白色卡片 |
| 凹陷容器 | 输入框、嵌套区域、次级工具区 | `#f8fafc` | `bg-slate-50` | 比卡片浅灰一档，避免内层过重 |
| 卡片边框 | 高级卡片和规格面板边界 | `#cbd5e1` | `border-slate-300` | 高级卡片优先使用虚线，数据表格可使用实线 |

### 文字层级

| 层级 | 用途 | 色值 | Tailwind 对应 | 说明 |
| --- | --- | --- | --- | --- |
| 主文字 | 标题、正文、关键数值 | `#0f172a` | `text-slate-900` | 柔和深色，适合长时间阅读 |
| 次要文字 | 描述、副标题、辅助说明 | `#475569` | `text-slate-600` | 与主文字形成清晰层级 |
| 辅助文字 | 小号标签、占位符、低优先级信息 | `#94a3b8` | `text-slate-400` | 不承载核心信息 |
| 禁用文字 | disabled 控件文字 | `#cbd5e1` | `text-slate-300` | 必须同时配合 disabled 状态 |

### 主操作

主操作与站点视觉强调分离。购买、结算、确认、提交等改变业务状态的操作使用深色，
不再默认使用翡翠绿。

| 用途 | 色值 | Tailwind 对应 | 使用方式 |
| --- | --- | --- | --- |
| 主操作默认 | `#0f172a` | `bg-slate-900` | 购买、结算、确认、提交 |
| 主操作悬停 | `#1e293b` | `bg-slate-800` | hover |
| 主操作按下 | `#020617` | `bg-slate-950` | active |
| 主操作文字 | `#ffffff` | `text-white` | 深色按钮上的文字和图标 |
| 主操作焦点 | Emerald 环 | `ring-emerald-600` | focus-visible 必须清晰可见 |

### 视觉与交互强调

Emerald 是站点视觉强调色，不是后台动态字段，也不是所有按钮的默认背景色。

| 用途 | 色值 | Tailwind 对应 | 使用方式 |
| --- | --- | --- | --- |
| 视觉强调 | `#059669` | `emerald-600` | 价格、库存、图标、较大字号数值、选中指示 |
| 强调深色 | `#047857` | `emerald-700` | 小号绿色文字、链接 hover、强调边框 |
| 强调极淡底 | `#ecfdf5` | `emerald-50` | 成功提示、健康状态、轻量标签 |
| 强调浅底 | `#d1fae5` | `emerald-100` | 选中项容器、选中卡片铺底 |

`#059669` 在白色背景上的对比度约为 `3.77:1`，适合较大的价格、图标和视觉
标记；小号正文或紧凑标签使用 `#047857`，其对比度约为 `5.48:1`。白色文字
放在 Emerald 背景上时，优先使用 Emerald-700。

### 语义状态

语义色用于表达状态，不用于替换主操作或站点视觉强调。背景保持浅色，文字和图标使用
对应的高对比深色。

| 状态 | 背景 | 文字/图标 | Tailwind 对应 |
| --- | --- | --- | --- |
| 正常/健康 | `#ecfdf5` | `#047857` | `bg-emerald-50 text-emerald-700` |
| 警告/注意 | `#fffbeb` | `#b45309` | `bg-amber-50 text-amber-700` |
| 危险/错误 | `#fef2f2` | `#b91c1c` | `bg-red-50 text-red-700` |
| 信息/中性 | `#eff6ff` | `#1d4ed8` | `bg-blue-50 text-blue-700` |

状态信息仍应通过文字、图标或辅助标记表达，不能只依赖颜色。

## 组件搭配

### Premium card

推荐的卡片结构如下：

```html
<section class="premium-card rounded-[24px] border border-dashed border-slate-300 bg-white">
  <p class="text-[10px] uppercase tracking-widest text-slate-400">LABEL</p>
  <h2 class="font-black text-slate-900">标题</h2>
  <p class="text-slate-600">描述或副标题</p>
  <div class="rounded-[16px] bg-slate-50">
    输入框或嵌套区域
  </div>
  <button class="bg-slate-900 text-white hover:bg-slate-800 active:bg-slate-950">
    主要操作
  </button>
</section>
```

视觉关系：

```text
页面底色 #f1f5f9
  -> 卡片表面 #ffffff
    -> 边框 #cbd5e1
      -> 标题/正文 #0f172a
      -> 描述 #475569
      -> 标签/占位符 #94a3b8
      -> 凹陷区 #f8fafc
      -> 主操作 #0f172a
         hover #1e293b
         active #020617
      -> 视觉强调 #059669 / #047857
```

### 输入框与嵌套区域

- 输入框和嵌套工具区使用 `#f8fafc`，圆角建议为 `16px`；
- placeholder 使用 `#94a3b8`，不能与已输入内容使用同一文字层级；
- 输入框边框使用 `#cbd5e1`，focus-visible 时使用 Emerald-600 焦点环；
- 嵌套区域不要再包一层重复的白色卡片，避免卡片套卡片；
- 表单控件的文字必须使用 Slate-900，不使用 Emerald 替代正文色。

### 标签、提示条和选中态

- 低优先级标签使用 Slate-400、uppercase 和较宽字距；
- 成功或健康状态使用 Emerald-50 背景与 Emerald-700 文字；
- 选中卡片可以使用 Emerald-100 作为铺底，边框或图标使用 Emerald-600；
- 警告、危险、信息分别使用 Amber、Red、Blue 的语义组合；
- 主操作按钮使用 Slate-900，不因“选中”或“强调”而自动变成 Emerald。

## 使用规则

1. 页面默认从 `bg-slate-100` 开始，禁止把纯白作为全局页面底色。
2. `.premium-card` 默认使用 `bg-white`，并使用 `border-dashed border-slate-300`
   保持轻量工业边界。
3. 输入框、内凹区和次级工具区使用 `bg-slate-50`。
4. 主操作使用 `bg-slate-900 text-white`，hover 使用 Slate-800，active 使用
   Slate-950。
5. Emerald-600 只用于站点视觉强调、价格、库存、图标和选中指示；小号文字优先
   使用 Emerald-700。
6. 主文字、次要文字和辅助文字分别使用 Slate-900、Slate-600、Slate-400；
   不用强调色替代正文层级。
7. 明色模式不新增紫色、棕色或暖灰作为主导色，也不使用大面积渐变来承担信息层级。
8. 文字、图标和状态不能只靠颜色区分；交互和无障碍标记必须同时存在。

## 令牌命名与迁移

全局实现应优先使用语义令牌，而不是在组件里直接写 HEX：

| 语义 | 推荐令牌 |
| --- | --- |
| 页面底色 | `--tz-surface-page` |
| 卡片表面 | `--tz-surface-card` |
| 内凹表面 | `--tz-surface-inset` |
| 主操作默认 | `--tz-action-primary` |
| 主操作悬停 | `--tz-action-primary-hover` |
| 主操作按下 | `--tz-action-primary-active` |
| 站点视觉强调 | `--tz-site-accent` |
| 站点视觉强调悬停/深色文字 | `--tz-site-accent-hover` |

禁止重新引入旧版 `--tz-b...` 命名的全局主题变量或其他兼容变量。后台动态字段
由后台配置提供；未配置时必须保持为空，不能由主题色兜底。主操作使用
`--tz-action-primary`，站点视觉强调使用 `--tz-site-accent`。

## 文档与迁移约定

本文件是项目明色模式色彩的唯一全局文档来源。新设计文档应引用本文件，不要在
功能文档中重新定义另一套颜色。

发现旧文档描述黑色表面、白色正文或其他暗色主题时：

- 如果文档仍是当前有效规范，应按本文件更新；
- 如果文档属于 `docs/archive/` 或 `nuxt-i18n/docs/archive/`，保留原文作为历史记录；
- 如果暗色描述只针对图片、视频或素材内部，应在文档中明确该范围，不要误认为它
  是应用表面规范。
