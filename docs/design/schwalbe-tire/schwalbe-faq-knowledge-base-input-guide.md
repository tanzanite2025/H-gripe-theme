# Schwalbe FAQ 内容边界指南

> 本文规定 FAQ 内容如何避免超出已有来源，不是商品录入流程，也不增加商品审批、复核或重复录入步骤。候选目录、模板型号自动回填和销售商品边界以 [Phase 1 商品模板实施指南](./phase1-schwalbe-tire-system-template-implementation-guide.md) 为准。

## 1. FAQ 与商品数据的关系

- 全谱系型号候选保存在独立目录，选型页可以展示尚未销售的型号，并标明是否存在对应销售商品。
- 新建销售 Product 时，在商品表单选择 Schwalbe Tire 模板及具体型号；型号字段从候选目录自动回填，销售资料仍保存在现有 Product/SKU 中。
- FAQ 文案不是商品字段，也不复制或替代候选目录；目录候选不表示有库存或可购买。
- 本指南不新增特殊 Admin 页面、商品资料审核或第二位管理员复核流程。

## 2. 内容来源规则

发布产品事实时，使用能直接支持该说法的 Schwalbe 官方产品页或官方技术说明，并链接到具体来源。型号相关结论应对应到具体型号和适用条件。

如果来源没有明确支持某个数字、结构、测试结果或适配结论，就不要把它写成 Schwalbe 官方事实。经销商文案、旧原型、行业经验和其他型号页面不能代替具体官方来源。

保留来源链接和核对日期，方便日后更新。此要求用于避免写错来源，不构成额外的商品审批流程。

## 3. 可使用的 FAQ 主题

下列主题可以围绕现有字段解释，但答案应限于实际页面与商品记录能够支持的内容：

1. **选型页为什么会有未上架型号？** 页面检索全谱系候选目录；每条结果都会标出是否存在对应销售商品。
2. **新建销售商品时怎样填写规格？** 选择 Schwalbe Tire 模板，再选目录中的具体型号，19 项官方字段会自动回填；Product/SKU 仍按普通商品流程保存。
3. **官网没有显示可选参数怎么办？** 留空，不用猜测值、零或其他型号的数据补齐。
4. **商品页的 Bar/PSI 能否直接说明轮圈兼容性？** 不能仅凭这些商品字段推导 Hookless 认证、轮圈适配或安全上限。
5. **目录型号是否表示有库存？** 不表示；只有匹配到真实销售 Product/SKU 后才显示商品链接、价格和库存。
6. **为什么选型页有 Telemetry Guide？** 它是独立的技术说明，不是商品字段；四个主题标签发布有官方来源支撑、用户能理解的 Radial 胎体、Protection Level 1–7 防刺结构、ADDIX 胶料和 Green Marathon 材料说明。ADDIX 标签保留 Race、4-Season、Speed、Mid（原 SpeedGrip）、Soft、Ultra Soft 和 Endurance 七条静态命名线，颜色只作视觉图例，默认只显示一个主题，不展示快照记录数、来源字符串分组或标签计数。Telemetry 内容不会改变商品模板，也不会把候选型号变成销售商品，并可在商品页或弹窗复用。
7. **为什么选型页要分页？** 当前目录候选每页 SSR 输出 20 条，`page` 与 `search` 保留在 URL，便于直链、刷新和搜索引擎抓取；分页只控制展示范围，不代表库存、购买资格或技术认证。

以上为边界示例，不代表必须创建五条 FAQ。

## 4. 旧 FAQ 草稿处理

旧稿中关于 ADDIX 胶料性能百分比、胎体滚阻降幅、胎唇伸长率、Hookless 安装禁令、统一 5.0 bar 上限、特定内宽的最小胎宽、TPU 内胎兼容性及车型推荐等内容，没有在本指南中得到逐条来源核对。

这些内容不得直接复制到生产 FAQ，也不得作为商品模板字段、自动筛选规则或适配结论。若后续需要说明某个主题，先找到能支持该具体说法和适用范围的官方来源，再按普通 FAQ 内容维护；不能拿旧原型或旧答案补证据。

## 5. 发布范围

如站点需要展示 Schwalbe FAQ，沿用现有 FAQ 内容能力。页面与结构化数据仅输出实际维护并展示的问答；不得预设“12 条官方问答”、伪造 FAQPage 答案或声称覆盖全系列。

商品录入继续使用现有商品新增/编辑保存流程，不因 FAQ 增加新的商品审核、复核或资料提交步骤。

FAQ、Telemetry Guide 和分页说明只能发布已维护且有来源支撑的内容；不得从旧 HTML 原型复制未核实的性能百分比、奖项、统一防刺等级、兼容性或安全结论。分页页面也不得为了 SEO 虚构未渲染的型号详情或销售状态。
